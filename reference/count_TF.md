# Count function for binary (true/false) variables

Count function for binary (true/false) variables

## Usage

``` r
count_TF(data, varName, popN, expectedCat = NA)
```

## Arguments

- data:

  input data.table

- varName:

  name of the variable column in data of interest

- popN:

  denominator; population N, numeric

- expectedCat:

  vector of expected categories; NA, unused in this function
