# Count function for categorical variables

Count function for categorical variables

## Usage

``` r
count_CAT(data, varName, popN, expectedCat)
```

## Arguments

- data:

  input data.table

- varName:

  name of the variable column in data of interest

- popN:

  denominator; population N, numeric

- expectedCat:

  vector of expected categories

## Value

one row for every value of expectedCat
